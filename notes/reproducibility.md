# Source provenance and reproducibility

This repository is derived from the user's uploaded `Instrumentation amplifier.zip`. Source `.asc` files are preserved unedited under [`evidence/original_schematics/`](../evidence/), except the 28-byte empty `Instrumentation_amplifier_ecg_common_mode_test.asc`, which was omitted as non-functional. Generated macOS `.DS_Store`, `__MACOSX`, `.db`, `.op.raw`, and the very large `.raw` files were omitted from the shareable repository.

| Main file | Original source and modifications |

## Important discrepancies in saved material

- `Instrumentation_amplifier_ecg_1percent_mismatch.log` and `.raw` record `A_cm≈0.005`, CMRR≈86.11 dB, but the corresponding saved `.asc` has **matched** output-stage values. The exact archived circuit modification cannot be validated from that file alone.
- `Instrumentation_amplifier_ecg_pure_common_mode_test.asc` is **not pure common-mode**: saved B1/B2 expressions include a differential 1.2 Hz component. Its archived `.raw` actually shows *pure common mode*, indicating the simulation was run using an earlier/altered version of the schematic.
- `Instrumentation_amplifier_ecg_practical.asc` has a basic 5 Hz, 1 mV stimulus, but its archived `.raw` and `.log` contain a 1.2 Hz differential signal plus 50 Hz interference; again the schematic was likely changed after the run. The archived **waveform is still real**; the saved practical `.asc` is not the complete reproduction recipe.
- The `FINAL_ECG` schematic originally referenced a PWL file in a user's Downloads folder, missing from the ZIP. This package reconstructs that file by sampling the archived `V(ecg)` trace at 1 ms intervals. The maximum reconstruction discrepancy evaluated against the 60,132 saved simulator points is **8.51e-11 V** (numerical post-processing only; does not validate circuit rerun). This is labeled reconstruction, **not an original PWL artifact**.

To fully verify the originally reported CMRR and interference demonstrations, rerun the curated schematic variants and save the resulting `.log` together with the exact `.asc` used. The archived numbers in the README must not be attributed to newly prepared simulations without verification.
