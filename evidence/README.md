# Original LTspice screenshots and project evidence

Place your **actual screenshots from your LinkedIn post or LTspice** here, for example:

- `01_original_3opamp_schematic.png`
- `02_original_gain_measurement.png`
- `03_original_common_mode_test.png`
- `04_original_resistor_mismatch_test.png`
- `05_original_ecg_demonstration.png`

They should show readable circuit values, graph axes, traces and simulator measurements. Do not add generated images and label them as original screenshots. After you upload, optionally embed the screenshot filenames in the top-level README using `![Description](evidence/your_file.png)`.

`original_schematics/` also stores the exact unchanged original `.asc` source files from the provided archive. The main `circuits/` copies are curated and may differ for reproducibility.

The text snippets here are faithful extracts of archived LTspice `.log` measurements, with user-specific file paths removed.
